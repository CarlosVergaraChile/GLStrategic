# Paquete web HEC Informe 01 — versión portable v09

## Estructura obligatoria
Subir estos elementos juntos, al mismo nivel:

- `index.html`
- `hec_diagnostico_v09_portable.html` (copia con nombre descriptivo)
- carpeta `HEC Informe 01 detalles/`
- carpeta `assets/`

## Hostinger
Copiar todo el contenido de esta carpeta a `public_html/` o a la subcarpeta del sitio. Abrir `index.html`.

## GitHub Pages
Subir todo el contenido a la raíz del repositorio o a `/docs` si se configura Pages desde `/docs`. El archivo `index.html` será la portada.

## Regla crítica
No subir solo el HTML principal: los botones de detalle dependen de la carpeta `HEC Informe 01 detalles/` y de `assets/`.

## Rutas
Las rutas son relativas y no contienen referencias a `C:\Users\...`, Google Drive local ni rutas absolutas.
